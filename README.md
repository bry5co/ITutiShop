
## ITutiShop 🛒
iTutiShop es una plataforma de comercio electrónico diseñada para facilitar la compra y venta de productos de manera rápida, segura y eficiente. Su objetivo principal es proporcionar una experiencia de usuario intuitiva y moderna tanto para compradores como para vendedores, integrando herramientas que optimizan el proceso de gestión de inventarios, transacciones y envíos.

La plataforma está dirigida a pequeñas y medianas empresas (PyMEs) que buscan digitalizar sus negocios, así como a consumidores interesados en acceder a una amplia variedad de productos desde la comodidad de sus hogares.

## Características Principales ✨
Catálogo de Productos: Visualización clara y categorizada de los productos disponibles.
Gestión de Usuarios: Autenticación y administración de cuentas de compradores y vendedores.
Carrito de Compras: Funcionalidad para agregar, eliminar y modificar productos antes de realizar la compra.
Sistema de Pedidos: Seguimiento en tiempo real del estado de los pedidos.
Métodos de Pago Seguros: Integración con pasarelas de pago confiables.
Panel de Administración: Herramientas para gestionar inventarios, ventas y estadísticas.
Notificaciones en Tiempo Real: Alertas sobre promociones, cambios en pedidos y actualizaciones de productos.
## Objetivos del Proyecto 🎯
Crear una plataforma que simplifique el comercio electrónico para negocios emergentes.
Proporcionar una interfaz atractiva y fácil de usar que mejore la experiencia del cliente.
Optimizar la gestión de inventarios, pedidos y pagos.
Facilitar la interacción entre compradores y vendedores de manera transparente y eficiente.
Garantizar la seguridad de los datos y transacciones realizadas en la plataforma.

## Requisitos previos 📋

- Tener instalado **XAMPP** en tu computadora.
- Un navegador web actualizado.

---

## Cómo usar este proyecto 🚀

1. **Clona este repositorio** en la carpeta `htdocs` de tu instalación de XAMPP:
   ```bash
   git clone https://github.com/bry5co/ITutiShop.git
   ```

2. Inicia el servidor de **Apache** desde el panel de control de XAMPP.

3. Accede al proyecto desde tu navegador utilizando:
   ```
   http://localhost/ITutiShop/
   ```

4. Interactúa con la aplicación agregando, editando o eliminando usuarios.
